# Apple Music Module for moOde

Module moOde pour l'intégration d'Apple Music.

## Installation

> Les instructions seront complétées à mesure du développement.

```bash
sudo bash applemusic/update/install.sh
```

## Composants

- `update/install.sh` : script d'installation du module sur un système moOde.
